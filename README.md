## Publish to grok.me

This sandbox cannot push a live grok.me URL. Publish from Grok Build Mode:

1. Go to https://grok.com/?mode=build
2. Attach or paste this project and say: “Publish this as my personal portfolio on grok.me.”
3. Use the Publish control in Build Mode for a grok.me link.
